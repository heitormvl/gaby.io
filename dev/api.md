## 🗂 Estrutura de API (mínima)

| Método               | Rota                                                                   | Função |
| -------------------- | ---------------------------------------------------------------------- | ------ |
| GET `/books`         | Lista todos os livros                                                  |        |
| POST `/books/import` | Importa o Excel                                                        |        |
| GET `/readings`      | Lista leituras                                                         |        |
| GET `/stats/summary` | Retorna estatísticas agregadas (gêneros, páginas x mês, páginas x ano) |        |
