## ⚙️ Stack

* **Frontend (Razor)**:

  * Manifest e Service Worker configurados
  * Páginas:

    * `/` → Dashboard (4 gráficos + resumo)
    * `/books` → Lista de livros
* **Backend (API .NET 8)**

  * MVVMC (`/books`, `/readings`, `/stats`)
    * EF Core + Identity + Data Annotations
  * Banco: SQL Server docker (dev) / SQL Server (prod)
