## 🎯 Funcionalidades Principais

- 📚 **Gerenciamento de Livros** - CRUD completo de livros, autores e editoras
- 📖 **Controle de Leituras** - Registre suas leituras com datas, status e páginas lidas
- ⭐ **Sistema de Avaliações** - Avalie livros de 0 a 5 estrelas
- 📊 **Dashboard Interativo** - Visualize estatísticas de leitura com gráficos
- 👥 **Multi-usuário** - Sistema de autenticação e perfis individuais
- 🔐 **Painel Admin** - Gerenciamento de usuários e permissões
- 🎨 **Interface Moderna** - Bootstrap 5 e design responsivo
